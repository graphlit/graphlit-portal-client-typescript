# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-11-03

### Added

- Initial release of Graphlit Portal Client SDK
- Project management operations (CRUD)
- Project subscription management
- Support for production and development environments via `portalUri` option
- Environment variable support (`GRAPHLIT_API_KEY`, `GRAPHLIT_ORGANIZATION_ID`, `GRAPHLIT_PORTAL_URI`)
- Full TypeScript support with GraphQL codegen
- Comprehensive README and examples
